\subsection{Study 1: Determining the Amount of Image Resources Required for Generalization}

This study focused on CV system performance with different numbers of available images for model calibration. Available images were randomly sampled from the \textit{Calibration} subset at sample sizes of 64, 256, and 1,024. Since the available dataset contained only 954 images, when the sample size was set to 1,024, the system sampled images with replacement until reaching 1,024 images. Due to data augmentation applied to increase image diversity, even two images sampled from the same original image can differ. The sampling process was repeated 50 times for each subset and sample size to avoid sampling bias. In addition to reporting standard machine learning detection metrics, this study examined correlations between automated and manual counts. Automated counts were obtained by summing ants detected with confidence scores above 0.5, while manual counts were derived from YOLO annotations labeled manually. Correlation was calculated using the Pearson correlation coefficient, which measures linear relationships between the two count sets. High correlation indicates that automated counting results are consistent with manual counts, while low correlation suggests discrepancies between methods.

When objects of interest are small, previous studies have demonstrated that model performance can be improved using Slicing Aided Hyper Inference (SAHI) \cite{akyon_slicing_2022}. This technique divides input images into smaller patches, enabling the model to focus on localized areas and potentially improve detection accuracy for small objects. We evaluated model performance both with and without SAHI on test images. SAHI implementation requires two key parameters: patch size and overlap size. Patch size determines the dimensions of each image patch, while overlap size controls the degree of overlap between adjacent patches. We explored three patch sizes by setting dividers of 2, 3, and 4, where patch size equals the shorter side of the image divided by the chosen divider. For example, when the divider is set to 2, patch size becomes half the length of the image's shorter side. We tested three overlap sizes: 0, 0.25, and 0.5, where an overlap size of 0 indicates no overlap between patches.

Since each parameter combination potentially yields different performance outcomes, we conducted a grid search evaluating all nine possible combinations of patch size and overlap size through hyperparameter tuning. Before testing the model on each subset, we sampled 10 images from the target subset to determine optimal parameter combinations for SAHI implementation. Given the absence of ground truth data for ant counts in these tuning images, we used high-confidence detections (confidence > 0.5) as a proxy for prediction quality. This unsupervised approach avoids data leakage issues since ground truth labels are not used during hyperparameter tuning.

Because the investigated factors—including calibration sample size, SAHI usage, model complexity, and background similarity may affect model generalization performance, an ordinary least squares (OLS) regression model was used to evaluate their impact:

\begin{equation}
y_{ijk} = \beta_0 + \beta_1 n_i + \beta_2 m_j + \beta_3 b_k + \varepsilon_{ijk}
\label{eq4}
\end{equation}

where $y_{ijk}$ is the model performance metric (e.g., mAP@0.5) for the $i$-th calibration sample size, $j$-th model complexity, and $k$-th background similarity; $\beta_0$ is the intercept; $\beta_1$, $\beta_2$, and $\beta_3$ are coefficients for calibration sample size, model complexity, and background similarity, respectively; and $\varepsilon_{ijk}$ is the error term. Calibration sample size $n_i$ is a categorical variable with three levels: 64, 256, and 1,024; model complexity $m_j$ is a categorical variable with three levels: YOLOv11n, YOLOv11m, and RT-DETR-L; and background similarity $b_k$ is a categorical variable with two prefixes: "A" and "B". The regression model was fitted using the Python Statsmodels library \cite{seabold_statsmodels_2010}.

Performance with and without SAHI was evaluated separately by statistically comparing mean Average Precision (mAP) metrics over the 50 iterations. We began by examining data distribution characteristics using the Shapiro-Wilk normality test \cite{shapiro_analysis_1965} for each performance distribution. When both distributions demonstrated normality, we assessed variance homogeneity through Levene's test \cite{levene_robust_1960}. The choice of parametric test depended on these preliminary assessments: Student's t-test was applied when assumptions of normality and equal variances were satisfied, while Welch's unequal variances t-test \cite{welch_generalization_1947} was used when variances differed significantly despite normal distributions. For performance distributions that failed normality assumptions, we employed the non-parametric Mann-Whitney U test \cite{mann_test_1947} to evaluate distributional differences. All statistical inferences were made using $\alpha$ = 0.05 as the significance threshold. Statistical analysis was conducted using the Python SciPy library \cite{virtanen_scipy_2020}.
